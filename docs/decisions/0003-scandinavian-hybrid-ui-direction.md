# Scandinavian Hybrid UI Direction

Vosio bude používat hybridní produktový směr:

- `/recordings` jako kompaktní inbox nahrávek,
- `/recordings/new` jako rychlá capture console pro live nahrávání nebo upload,
- `/recordings/[recordingId]` jako transcript studio pro práci s jednou nahrávkou.

Vizuální styl je skandinávsky střídmý pracovní workspace. To znamená menší běžné písmo, malé ikony, neutrální černo-šedý dark mode, bílý a světle šedý light mode, málo dekorací a žádné velké hero bloky uvnitř aplikace.

Rozhodnutí:

- Zachovat logiku aplikace, ale změnit UI patterny a vizuální jazyk.
- Hlavní objekt je vždy nahrávka.
- AI zpracování patří do detailu nahrávky, ne jako dominantní globální panel.
- Live nahrávání a upload mají být na nové nahrávce vidět vedle sebe.
- Přepis má být čitelný a kompaktní i pro dlouhé hovory.
- Časová osa má být obsahová AI kapitola hovoru, ne technický seznam segmentů po sekundách.
- Tmavý i světlý režim jsou plnohodnotné.

Zakázané směry:

- velké ikony,
- velké display písmo pro běžný pracovní obsah,
- hero sekce v aplikaci,
- dekorativní waveform jako hlavní plocha,
- tyrkysové UI všude,
- marketingový styl nebo benefit strip v aplikaci.
